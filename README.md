# ◆ Legend Cut

مونتاج كامل بالذكاء الاصطناعي لويندوز. من عائلة Legend.

ترفع المقطع، والذكاء الاصطناعي يقص الممل، ويضيف موشن جرافيك (عناوين متحركة، وكابشن كلمة كلمة، وزوم)، وبعدها تعدّل اللي تبيه أو تكلم المساعد يعدّل لك.

## التنصيب
نزّل `LegendCut-Setup.exe` من [Releases](https://github.com/MATRIX5578/legend-cut/releases/latest) وشغّله.

## أول تشغيل
اضغط **«سجّل دخول كلود»** وسجّل بحسابك Pro أو Max من المتصفح. تسويها مرة وحدة بس، بدون API key وبدون دفع إضافي.

## المزايا
- يقص تلقائياً الصمت والتكرار والتهتهة والأجزاء المملة
- عناوين موشن متحركة، وكابشن متحرك عربي وإنجليزي، وزوم على اللحظات القوية
- تايملاين تعديل: كليك تشيل أو ترجع الجزء، وكليك يمين للزوم
- مساعد ذكاء اصطناعي داخل التطبيق تكلمه بالعامية ويعدّل المقطع
- أي صيغة وأي مقاس (طولي، عرضي، مربع) وأي طول
- تحديثات تلقائية من داخل التطبيق
